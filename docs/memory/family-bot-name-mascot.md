**Mascot**
- Julian wants a mascot. The persona is like Donna (Suits) or Pam (The Office): one cute character that appears only when the assistant speaks, inside an otherwise Notion-calm UI. No guilt-tripping like Duolingo.
- Julian chose the squirrel as the mascot on 2026-10-23.
- Name ideas offered: "Kobel" (the squirrel's nest) as the app with "Hazel" as the assistant (my favourite), "Hörnchen", or "Hazel" for both. "Hazel" was checked on 2026-10-23 and is crowded: hazelhere.com (a childcare AI with a squirrel mascot named Hazel), Noodlesoft Hazel and hazel.ai. Hazel is off as the app name. Next ideas: Kobel as the app with Eike or Pip as the mascot (not yet checked). Julian also likes the beaver, but the English "beaver" is vulgar slang, so it should not be in the app name.
